# 🎧 Call Center Brand – Color Palette & UI Design Guide

This document provides a **ready-to-use brand color palette** for a **Call Center System**, designed for long working hours, dashboards, agent screens, and supervisor monitoring.

---

## 🎯 Brand Objectives
- Enterprise & professional look
- Eye-friendly for long agent shifts
- Optimized for dashboards & live monitoring
- Supports **Light Mode & Dark Mode**
- Scalable for CRM, AI, and Voice features

---

## 🎨 Option 1: Professional Blue (Enterprise Style)
**Best for corporate and enterprise call centers**

### Primary Colors
- Brand Blue: `#0B5ED7`
- Dark Blue (Sidebar / Headers): `#084298`

### Secondary Colors
- Light Blue (Highlights): `#6EA8FE`
- Soft Background: `#E7F1FF`

### Neutral Colors
- Primary Text: `#0F172A`
- Muted Text: `#64748B`
- Page Background: `#F8FAFC`

### Status Colors
- Success (Answered Call): `#198754`
- Warning (On Hold): `#FFC107`
- Error (Missed / Failed): `#DC3545`
- Info (Active Call): `#0DCAF0`

---

## 🧩 Recommended UI Usage Mapping

| UI Element | Recommended Color |
|-----------|------------------|
| Sidebar | Dark Primary |
| Primary Button | Brand Color |
| Secondary Button | Soft Accent |
| Active Call | Info / Accent |
| Answered Call | Success |
| Missed Call | Error |
| Charts & KPIs | Brand + Accent |

---

## 🛠 Implementation Notes
- Use **status colors consistently** across all modules
- Avoid pure white for large areas (use soft backgrounds)
- Maintain AA/AAA contrast ratios for accessibility
- Dark mode should be available for agents by default
